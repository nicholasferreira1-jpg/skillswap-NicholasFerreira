# skillswap-NicholasFerreira

## Description

Skill Swap is a platform for college students and recent graduates who are seeking help in an specific skill or need a way to earn money. Students can find affordable tutors for the skills they need and pay for it or offer their own skill to trade with the tutor so they can do a hour-for hour skill trade with no money exchange. 


## Technologies Used

- **Frontend:** HTML, CSS, Javascript
- **Backend:**  Node.js, Express
- **Database:** PostgreSql, with Sequelize
